Managing Your PiSelfhosting Environment with Ease

The PiSelfhosting project includes a suite of specialized tools and utility scripts designed to simplify the ongoing management, configuration, and maintenance of your self-hosted services. These tools abstract away complex commands, provide interactive interfaces, and automate routine tasks.

By leveraging these utilities, you can efficiently customize your setup, manage certificates, configure new devices, and monitor your system's health.

---

Dashy Tile Configuration Tool

This tool automates the process of populating your Dashy dashboard with links to your deployed PiSelfhosting services. It ensures that your dashboard always reflects your current active services.

Components:

  • run-dashy-tile-config-tool.sh: The bash wrapper script that executes the Python tool in a Docker container. It handles image building and passes necessary environment variables.
  • dashy_tile_config_tool.py: The Python script that reads your selected components from selected_components.txt and generates/updates Dashy's conf.yml with appropriate service tiles (links). It uses your defined domain to create service URLs.

Usage:

Run this tool whenever you've added or removed services to update your Dashy dashboard:

bash /home/PiSelfhosting/scripts/run-dashy-tile-config-tool.sh

After running, remember to restart Dashy for changes to take effect: bash /home/PiSelfhosting/scripts/restart-all.sh dashy.

Planned Enhancement: Camera Stills on Dashy: Future development aims to extend this tool's functionality to dynamically display live camera stills or updated snapshots from Frigate directly on your Dashy dashboard tiles, providing an even richer monitoring experience.

Frigate Camera Configuration Tool

This tool simplifies the process of adding and configuring IP cameras for your Frigate NVR. It supports automated discovery and provides interactive guidance.

Components:

  • run-frigate-camera-config-tool.sh: The bash wrapper that executes the Python script directly within your running Frigate container.
  • frigate_camera_config_tool.py: The Python script that offers:
    • ONVIF camera discovery (via network scan or IP range).
    • RTSP stream testing using FFprobe.
    • Selection from a list of community_cameras.json presets for common camera models.
    • Interactive prompts for camera details and optional FFmpeg input arguments.
    • Automatic update of your Frigate config.yml.
    • Optional configuration for Google Coral TPU.
  • community_cameras.json: A JSON file containing predefined RTSP URL templates for various IP camera models, simplifying manual entry.

Usage:

Run this tool to add or reconfigure cameras for Frigate:

bash /home/PiSelfhosting/scripts/run-frigate-camera-config-tool.sh

After running, restart Frigate for changes to take effect: bash /home/PiSelfhosting/scripts/restart-all.sh frigate.

Mailserver Configuration Tool

This tool is designed to assist with the complex setup and configuration of your self-hosted Mailserver, ensuring proper domain, user, and security settings.

Components:

  • run-mailserver-config-tool.sh: The bash wrapper script that executes the underlying Python configuration tool (mailserver_config_tool.py) within a Docker container.
  • mailserver_config_tool.py: (Details pending final implementation). This Python script will likely handle interactive prompts for mail server settings, domain configuration, user creation, and generation of necessary configuration files for components like Exim4 and Dovecot.

Usage:

Use this tool to configure your Mailserver after its initial deployment:

bash /home/PiSelfhosting/scripts/run-mailserver-config-tool.sh

After running, remember to restart the Mailserver for changes to take effect: bash /home/PiSelfhosting/scripts/restart-all.sh mailserver.

SSL Certificate Manager

This tool provides a guided process for obtaining and managing SSL/TLS certificates for your self-hosted services, essential for enabling secure HTTPS access.

Components:

  • run-ssl-cert-manager.sh: The bash wrapper script that executes the Python tool in a Docker container.
  • ssl_cert_manager.py: The Python script that offers:
    • Guidance for obtaining **Let's Encrypt certificates via Nginx Proxy Manager**, including crucial prerequisites like port forwarding and DNS configuration.
    • The ability to **generate self-signed certificates** for internal use.
    • A method to **copy your own existing SSL certificate files** into the centralized certificate storage.
    • It creates the centralized certificate storage directory at /home/PiSelfhosting/certs/ on your host.

Usage:

Use this tool to set up or manage your SSL certificates:

bash /home/PiSelfhosting/scripts/run-ssl-cert-manager.sh

After generating or placing certificates, remember to update your services' configurations (e.g., Mailserver, Nginx Proxy Manager) to point to the new certificate files and then restart those services.

Docker Stats Updater

This utility provides a simple, web-based overview of your Docker containers' real-time status and statistics.

Components:

  • update-docker-stats.sh: The bash script that periodically captures Docker container statistics using docker ps and formats them into an HTML file (index.html). This HTML file is then served by the Docker Monitor Nginx container.
  • Docker Monitor Service: A lightweight Nginx container that serves the index.html generated by the updater script. Its Docker Compose definition is dynamically included in the main unified docker-compose.yml by the deploy.sh script.

Usage:

To enable and maintain the Docker Stats page:

  1. Ensure the Docker Monitor service is selected during setup.sh and deployed with deploy.sh.
  2. Set up a Cron job on your Raspberry Pi to run the updater script periodically (e.g., every 5 minutes) to keep the stats page up-to-date.
crontab -e
# Add a line like (e.g., every 5 minutes):
*/5 * * * * /home/PiSelfhosting/scripts/update-docker-stats.sh > /dev/null 2>&1

Access the page via your browser at http://[your-pi-ip]:8088 (or the port you configured).
