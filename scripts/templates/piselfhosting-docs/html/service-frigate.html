Frigate: AI-Powered NVR

Frigate is an open-source Network Video Recorder (NVR) with a focus on real-time AI object detection. It's designed for local processing, ensuring your camera feeds never leave your home. Frigate excels at minimizing false positives by using advanced AI to identify relevant objects like people, cars, and animals, rather than relying solely on motion detection.

Within the PiSelfhosting project, Frigate provides a powerful and customizable solution for managing and monitoring your IP cameras. It integrates seamlessly with other services, particularly MQTT for notifications and Home Assistant for automation.

---

Detailed Functionality

Key Features:

  • Real-time Object Detection: Frigate uses AI models to detect objects in real-time, reducing false positives compared to traditional motion detection.
  • Multi-Camera Support: Manage multiple IP cameras simultaneously.
  • Customizable Zones: Define specific areas within the camera's view for focused object detection and alerting.
  • Hardware Acceleration: Supports hardware accelerators like Google Coral and GPUs for improved performance.
  • MQTT Integration: Publishes events and object detections via MQTT, enabling integration with other systems.
  • Home Assistant Integration: Provides a custom component for tight integration with Home Assistant.
  • Recording: Captures and stores video clips based on detection events or 24/7.
  • Web Interface: User-friendly web interface for configuration and monitoring.
  • API: Provides an API for accessing events, clips, and other data.

PiSelfhosting Integration:

The PiSelfhosting project simplifies the deployment and configuration of Frigate through the following:

  • Docker Compose Template: The docker-compose.yml.template file in /home/PiSelfhosting/scripts/templates/frigate/ defines the Frigate service, including:
    • Image: blakeblackshear/frigate:stable (or a specific version).
    • Ports: Mapping for the web UI (default 5000) and optional ports for hardware acceleration.
    • Volumes: Mapping for the configuration file (config.yml) and media storage.
    • Environment variables: Configuration options passed to the Frigate container.
    • Hardware acceleration: Configuration for Coral USB accelerator or GPU.
    • MQTT: Configuration for connecting to the Mosquitto MQTT broker.
  • Configuration Tool: The frigate_camera_config_tool.py script and run-frigate-camera-config-tool.sh wrapper automate camera configuration, including:
    • ONVIF camera discovery.
    • RTSP stream testing.
    • Camera preset selection from the community_cameras.json file.
    • Dynamic updates to the Frigate config.yml.

Expanding with New Services/Applications:

PiSelfhosting is designed to be extensible. Here's how you can integrate Frigate with services not directly managed by the project:

  1. MQTT Integration: Frigate publishes a wealth of data via MQTT. You can subscribe to these topics from other applications:
    • frigate/events: Detailed information about detected objects, including bounding box coordinates, labels, and timestamps.
    • frigate/camera_name/object_name/snapshot: JPEG encoded images of detected objects.
    • frigate/camera_name/object_name/active: Count of active objects for a specific camera and object type.
    • Refer to the Frigate MQTT documentation for a complete list of topics.

    Example: You could use Node-RED to subscribe to Frigate's MQTT topics and trigger actions based on detected objects (e.g., send a notification, control lights, etc.).

  2. Frigate API: Frigate provides an HTTP API for accessing events, clips, and snapshots.

    Frigate API Documentation

    Example: You could write a custom script to retrieve recent events and display them on a dashboard.

  3. Home Assistant Integration: While PiSelfhosting doesn't directly manage Home Assistant, the tight integration between Frigate and Home Assistant makes it a natural extension. You can use the Home Assistant Frigate integration to:
    • View live camera streams.
    • Browse recordings and snapshots.
    • Receive notifications based on events.
    • Automate actions based on object detection (e.g., turn on lights when a person is detected).

    Frigate Home Assistant Integration Documentation

Configuration Details

The primary configuration for Frigate is located in the config.yml file. The PiSelfhosting project provides a basic template, but you'll likely need to customize it for your specific cameras and needs. Key configuration areas include:

  • Cameras: Defining your cameras, including RTSP stream URLs, resolutions, frame rates, and zones. Frigate Camera Setup Documentation
  • Objects: Specifying which objects to detect (person, car, etc.) and tuning detection parameters.
  • Zones: Defining areas of interest within the camera's view. Frigate Zones Documentation
  • Record: Configuring recording behavior (24/7, based on events, etc.).
  • FFmpeg: Tuning FFmpeg input and output arguments for optimal performance and compatibility. Frigate FFmpeg Presets Documentation
  • Hardware Acceleration: Configuring Coral USB accelerator or GPU for object detection.
  • MQTT: Configuring the MQTT connection for integration with other systems.

Troubleshooting

If you encounter issues with Frigate, consider the following:

  • Check the Frigate logs: Use docker logs piselfhosting-frigate to view the container's logs for errors.
  • Verify your camera streams: Ensure your RTSP streams are working correctly.
  • Review the Frigate configuration: Double-check your config.yml for any errors.
  • Consult the Frigate documentation: The official Frigate documentation is a valuable resource. Frigate Documentation
