phpMyAdmin: Web-based MariaDB Management

phpMyAdmin is a free and open-source web-based graphical interface tool written in PHP, designed to handle the administration of MySQL or MariaDB databases. It provides a user-friendly way to manage your databases, tables, columns, relations, indexes, users, and permissions, as well as execute SQL statements directly from your web browser.

In the PiSelfhosting project, phpMyAdmin integrates directly with your deployed **MariaDB** service, giving you an easy visual tool to manage your application databases (like Nextcloud's database) without needing to use the command line.

---

Detailed Functionality

Key Features:

  • Database Management: Create, drop, and modify databases, tables, and views.
  • Data Manipulation: Insert, edit, delete, and browse data within tables.
  • SQL Query Execution: Execute SQL statements directly with an intuitive interface.
  • User & Permission Management: Manage database users and their privileges.
  • Import/Export: Easily import and export database structures and data.
  • Graphical Interface: Simplifies complex database operations through a web UI.

PiSelfhosting Integration:

The PiSelfhosting project automates the deployment of phpMyAdmin to provide a convenient interface for your MariaDB:

  • Docker Compose Template: The docker-compose.yml.template file in /home/PiSelfhosting/scripts/templates/phpmyadmin/ defines the phpMyAdmin service. Key aspects include:
    • Image: It uses arm64v8/phpmyadmin:latest, which is specifically optimized for ARM-based devices like the Raspberry Pi, ensuring compatibility and performance.
    • Ports: Maps the web UI to port 8083 on your host.
    • Environment variables:
      • PMA_HOST: mariadb: Connects phpMyAdmin to your MariaDB service, using its Docker service name.
      • PMA_PORT: 3306: Specifies the standard MariaDB port.
      • MYSQL_ROOT_PASSWORD: ${DB_PASS}: Provides phpMyAdmin with the root password for your MariaDB instance, which is retrieved from your .env file. This allows phpMyAdmin to manage all databases.
    • Dependency: The depends_on: - mariadb ensures that MariaDB is running before phpMyAdmin attempts to connect.

Access & Usage:

Once deployed, you can access phpMyAdmin through your web browser:

  • Access URL: Navigate to http://[your-pi-ip]:8083 in your web browser.
  • Login Credentials: You can log in using the MariaDB root user (`root`) and the password you set during the PiSelfhosting setup (`DB_PASS` from your `.env` file). Alternatively, you can log in with any other MariaDB user accounts you have created.

Troubleshooting

If you encounter issues with phpMyAdmin:

  • Check phpMyAdmin logs: Use docker logs piselfhosting-phpmyadmin for any errors.
  • Verify MariaDB Status: Ensure your MariaDB container is running and accessible. Check docker logs piselfhosting-mariadb.
  • Connection Credentials: Double-check that the `MYSQL_ROOT_PASSWORD` (or `PMA_USER`/`PMA_PASSWORD` if using) in the phpMyAdmin Docker Compose definition is correct and matches your MariaDB setup.
  • Port Conflicts: Ensure port 8083 is not being used by another application on your Raspberry Pi.
  • Network Connectivity: Confirm phpMyAdmin can reach MariaDB over the `piselfhosting_net` Docker network.
  • Official Documentation: Refer to the official phpMyAdmin documentation for more in-depth troubleshooting.
