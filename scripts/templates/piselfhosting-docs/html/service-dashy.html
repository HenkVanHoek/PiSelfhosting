Dashy: Your Personal Dashboard

Dashy is a highly customizable, modern, and privacy-respecting dashboard designed for self-hosting. It provides a central place to access all your self-hosted services, links, and important information. With its clean interface and extensive customization options, Dashy helps you organize your digital life.

Within the PiSelfhosting project, Dashy serves as your primary homepage, offering quick access to all the services you've deployed and configured.

---

Detailed Functionality

Key Features:

  • Centralized Access: A single point of access for all your self-hosted applications and external links.
  • Highly Customizable: Supports various themes, layouts, icon packs, and custom CSS.
  • Dynamic Content: Tiles can display real-time status checks, fetched data, and even integrate with APIs.
  • Search & Filtering: Quickly find services with built-in search and filtering capabilities.
  • Authentication: Optional authentication methods to secure your dashboard.
  • Easy to Use: Intuitive interface for adding, editing, and organizing your links.

PiSelfhosting Integration:

The PiSelfhosting project automates the setup and initial configuration of Dashy, making it ready to use with your deployed services:

  • Docker Compose Template: The docker-compose.yml.template file in /home/PiSelfhosting/scripts/templates/dashy/ defines the Dashy service, including:
    • Image: lissy93/dashy:2.1.1 (or a specific version).
    • Ports: Mapping for the web UI (default 8080 for HTTP, 4443 for HTTPS).
    • Volumes: Mapping for the configuration directory (conf.yml).
    • Environment variables: User/Group IDs (PUID, PGID) and timezone.
    • extra_hosts: Dynamically adds an entry for your main domain to the container's hosts file, facilitating access to services proxied by Nginx Proxy Manager.
  • Configuration Tool: The dashy_tile_config_tool.py script and its wrapper run-dashy-tile-config-tool.sh are designed to automatically populate your Dashy dashboard.
    • It reads your selected components from selected_components.txt and gathers details from components_list.txt.
    • It then generates the conf.yml file for Dashy, creating appropriate sections and tiles (links) for each of your deployed PiSelfhosting services.
    • This ensures your dashboard is automatically populated with links to services like Frigate, Nextcloud, Pi-hole, etc., using the domain you specified during setup.
  • Future Enhancement: Camera Stills:

    A planned future enhancement is to extend Dashy's integration with Frigate to display **live camera stills** or dynamically updated images on your dashboard tiles. This would provide an even quicker visual overview of your camera feeds directly from your Dashy homepage, leveraging Frigate's snapshot capabilities.

Configuration Details:

While much of Dashy's initial setup is automated, you can further customize its appearance and content.

  • Main Configuration File: The primary configuration file for Dashy is conf.yml, located in /home/PiSelfhosting/docker/dashy/config/. While this file is largely managed by dashy_tile_config_tool.py, you can manually edit it for advanced customizations (e.g., adding custom themes, more sections, or specific widget configurations).
  • Editing conf.yml: If you manually edit conf.yml, remember to restart the Dashy container for changes to take effect: bash /home/PiSelfhosting/scripts/restart-all.sh dashy.
  • Themes & Layouts: Explore Dashy's extensive documentation for more options on themes, layouts, and other visual settings.

Troubleshooting

If your Dashy dashboard isn't displaying correctly or links aren't working:

  • Run the config tool again: Execute bash /home/PiSelfhosting/scripts/run-dashy-tile-config-tool.sh to re-generate the conf.yml, especially after adding or removing services.
  • Check Dashy logs: Use docker logs piselfhosting-dashy to identify any errors during startup or operation.
  • Verify .env variables: Ensure your DOMAIN and other relevant variables are correctly set in /home/PiSelfhosting/.env.
  • Nginx Proxy Manager: If you're accessing Dashy via a subdomain (e.g., dashboard.yourdomain.com), verify your Nginx Proxy Manager setup for the Dashy host.
  • Dashy Documentation: Consult the official Dashy documentation for in-depth troubleshooting and advanced features. Dashy Documentation
