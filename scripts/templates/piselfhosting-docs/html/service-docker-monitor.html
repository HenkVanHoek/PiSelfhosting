Docker Monitor: Simple Docker Stats Page

The Docker Monitor service provides a very lightweight and quick way to view the status of your Docker containers via a web browser. Instead of logging into your Raspberry Pi and running docker ps, you get a simple, auto-refreshing HTML page displaying key information about your running services.

This service is designed for a quick overview and acts as a basic health check for your PiSelfhosting environment without requiring complex monitoring tools.

---

Detailed Functionality

Key Features:

  • Web-based Display: View container status from any device on your network via a web browser.
  • Auto-Refresh: The page automatically updates every 60 seconds, providing near real-time data.
  • Key Metrics: Displays container ID, Name, Image, Command, Creation Time, Status, and Ports.
  • Lightweight: Uses a static HTML file and a simple Nginx server, consuming minimal resources.
  • Responsive Design: The HTML styling adjusts for various screen sizes, including mobile devices.

PiSelfhosting Integration:

The Docker Monitor service is integrated into PiSelfhosting as follows:

  • Docker Compose Definition: The deploy.sh script dynamically adds the Docker Monitor's service definition into the main, unified docker-compose.yml file when 'docker-monitor' is selected as a component. This typically involves:
    • Using a lightweight Nginx image like nginx:alpine.
    • Mapping to a specific port on your host (e.g., 8088), allowing you to access the web page.
    • Mounting a local html directory (where the generated HTML file resides) to Nginx's web root within the container.
  • Update Script: The update-docker-stats.sh script is responsible for generating the index.html file with the latest Docker stats.
    • This script runs docker ps --format ... to gather container data.
    • It then embeds this data into an HTML structure.
    • For continuous updates, you are instructed to set up a Cron job to execute update-docker-stats.sh periodically (e.g., every 5 minutes).

Access & Usage:

Once deployed and the update script is running via cron, you can access your Docker stats page:

  • Access URL: Navigate to http://[your-pi-ip]:8088 (or the port you configured) in your web browser.
  • Updates: The page will automatically refresh to show the latest statistics.

Troubleshooting

If your Docker Monitor page isn't working or updating:

  • Check Docker Monitor logs: Use docker logs piselfhosting-docker-monitor to see if the Nginx web server is running correctly.
  • Verify update-docker-stats.sh execution: Ensure the script is actually running. You can try running it manually: bash /home/PiSelfhosting/scripts/update-docker-stats.sh and check for errors.
  • Cron Job: Confirm your cron job is correctly set up using crontab -l and that it has executable permissions.
  • File Permissions: Ensure the /home/PiSelfhosting/docker/docker-monitor/html directory and the index.html file have correct read/write permissions for the user running the cron job and the Nginx container.
  • Port Conflicts: Ensure the port for Docker Monitor (e.g., 8088) is not in use by another application.
